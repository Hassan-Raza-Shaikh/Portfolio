# Personal Developer Portfolio - Next.js & TypeScript

![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=for-the-badge&logo=typescript&logoColor=white)
![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-38B2AC?style=for-the-badge&logo=tailwind-css&logoColor=white)

A responsive, static personal portfolio website designed to present skills, academic projects, and software repositories.

## Key Features
*   **Next.js Server-Side Framework**: Fully structured components and layouts.
*   **TailwindCSS Styling**: Interactive, animated glassmorphism interfaces.
*   **Static Netlify Build**: Configurations in `netlify.toml` mapping redirects and page deployments.

## Setup Instructions
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the local server:
   ```bash
   npm run dev
   ```
3. Compile production builds:
   ```bash
   npm run build
   ```
